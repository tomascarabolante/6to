# Raiz & Rastro

Sitio web estático de ejemplo para un emprendimiento de objetos hechos con materiales recuperados.

## Archivos

- `index.html`: presentación, llamado a la acción y carrusel Bootstrap.
- `info.html`: historia, misión, valores y equipo.
- `contacto.html`: datos de contacto y formulario con validación JavaScript.
- `style.css`: estilos propios, colores, tipografías y responsive.
- `script.js`: botón volver arriba y validación/confirmación del formulario.

Las imágenes actuales son de ejemplo y están cargadas desde Unsplash. Se pueden reemplazar por imágenes locales cuando estén disponibles.
